### Задание 3 — Векторный индекс базы знаний

1. Выбор эмбеддинг-модели

Для создания векторного индекса была выбрана локальная модель эмбеддингов:

Модель: sentence-transformers/all-MiniLM-L6-v2

Тип: Sentence Transformers

Размер эмбеддинга: 384

Развёртывание: локальное (без передачи данных во внешние сервисы)

Данная модель была выбрана, так как она обеспечивает хороший баланс между качеством семантического поиска и скоростью работы на CPU, а также соответствует выбранной архитектуре варианта B (гибридный RAG) — локальные эмбеддинги + локальный векторный индекс.

2. Подготовка и чанкинг документов

В качестве базы знаний использовалась папка knowledge_base/, созданная в Задании 2, содержащая 35 уникальных документов с вымышленными сущностями.

Для разбиения документов на чанки использовался RecursiveCharacterTextSplitter со следующими параметрами:

Размер чанка: 1000 символов

Overlap: 150 символов

Для каждого чанка сохранялись метаданные:

source — имя исходного файла,

title — заголовок документа,

chunk_id — порядковый номер чанка внутри документа.

3. Генерация эмбеддингов и создание индекса

Для всех чанков были сгенерированы эмбеддинги с помощью выбранной модели.
Эмбеддинги были загружены в локальный векторный индекс FAISS.

Артефакты индекса:

index/faiss.index

index/index.pkl

Статистика индексации:

Количество документов: 35

Количество чанков: 1847

Время генерации индекса: ~20.55 секунд

4. Пример запроса к индексу (проверка качества)
Пример запроса:
What is Synth Flux and who can use it?

Найденные чанки (фрагмент):

source: synth-flux.md, chunk_id: 0

source: synth-flux.md, chunk_id: 1

source: lea-orgen.md, chunk_id: 42

source: astra-monks.md, chunk_id: 13

Результаты поиска подтверждают, что индекс корректно находит семантически релевантные фрагменты, относящиеся к вымышленному понятию Synth Flux, что подтверждает корректную работу retrieval-механизма.

5. Вывод

В рамках задания был успешно создан локальный векторный индекс базы знаний:

использована локальная embedding-модель,

реализован чанкинг с сохранением метаданных,

построен FAISS-индекс,

проверена корректность семантического поиска.

Созданный индекс готов к использованию в RAG-пайплайне на этапе генерации ответов.
