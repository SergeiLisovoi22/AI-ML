Задание 4. Реализация RAG-бота с техниками промптинга
Цель

Реализовать работающего RAG-бота, который использует векторную базу знаний для поиска информации, формирует ответы с опорой на найденные документы и применяет техники Few-shot prompting и Chain-of-Thought (CoT).

Архитектура решения

Используется гибридная RAG-архитектура:

Embeddings: sentence-transformers/all-MiniLM-L6-v2 (локально)

Vector DB: FAISS (локальный индекс из Задания 3)

LLM: OpenAI Chat API

Интерфейс: консольный REPL-бот

Документы и эмбеддинги не покидают локальный контур. В LLM передаётся только пользовательский запрос и отобранные релевантные чанки.

Реализация RAG-пайплайна

Бот выполняет следующие шаги:

Принимает текстовый запрос пользователя.

Преобразует запрос в эмбеддинг тем же энкодером, что использовался при индексации.

Выполняет поиск ближайших чанков в FAISS.

Проверяет релевантность результатов (порог уверенности).

Формирует промпт:

system-инструкция,

few-shot примеры,

найденные фрагменты базы знаний,

вопрос пользователя.

Отправляет промпт в LLM.

Возвращает ответ, список источников и шаги рассуждения.

При недостаточной релевантности корректно отвечает: «Я не знаю».

Few-shot prompting

В промпт добавлены заранее подготовленные примеры из той же предметной области, что и база знаний:

Q: What is Synth Flux?
A: Synth Flux is a metaphysical energy that connects all living things.

Q: What is Void Core?
A: Void Core is a massive artificial structure used as a central weapon platform.


Это помогает стабилизировать формат и стиль ответов.

Chain-of-Thought (CoT)

В system-промпте задано требование объяснять ход рассуждений.
Ответы модели содержат блок Steps, описывающий логические шаги получения ответа.

Пример:

Найден документ, описывающий Synth Flux.

В тексте указано, что Synth Flux — универсальная энергия.

Следовательно, Synth Flux используется чувствительными к ней персонажами.

Интерфейс

Реализован простой консольный бот (REPL):

🧠 RAG Bot (type 'exit' to quit)
> What is Synth Flux?
A: ...
Sources: synth-flux.md, astra-monks.md
Steps: ...

Примеры успешных диалогов

Запрос: What is Synth Flux?
Ответ: описание Synth Flux с источниками synth-flux.md, astra-monks.md.

Запрос: Explain Photon Blade and its typical users.
Ответ: описание Photon Blade с ссылками на соответствующие документы.

Запрос: What is Void Core and why is it important?
Ответ: описание Void Core с указанием источников.

Примеры ответа «Я не знаю»

Запрос: что такое synth flux? (на русском языке)

Ответ:

Я не знаю.

Steps:
1) Выполнен поиск по векторному индексу.
2) Найденные фрагменты недостаточно релевантны.

Sources:
- (нет надёжных источников)


Это демонстрирует корректную обработку случаев, когда бот не уверен в ответе.

Результат

В результате реализован:

работающий RAG-бот;

retrieval + generation;

few-shot prompting;

chain-of-thought;

корректная обработка неопределённых запросов.

Решение готово к расширению (API, Telegram-бот, корпоративный ассистент).
